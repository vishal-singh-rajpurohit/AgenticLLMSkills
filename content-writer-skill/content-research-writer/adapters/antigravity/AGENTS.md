# Editorial Safety & Publishing Guardrails

When using `content-research-writer`:

1. Never publish or write approved articles into production databases, CMS records, or site source files without explicit user confirmation on the exact previewed version.
2. Never fabricate facts, statistics, client stories, testimonials, author credentials, image licenses, or internal URLs.
3. Never use hardcoded DB/CMS credentials or bypass authentication/validation layers.
4. Always inspect the website/repository before asking discovery questions or recommending publishing changes.
5. Verify published routes, links, metadata, images, and sitemap discoverability after implementation.
