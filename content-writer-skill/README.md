# Content Writer Skill Repository

This repository packages the **`content-research-writer`** universal Agent Skill inside [`content-research-writer/`](content-research-writer/README.md).

> **Why this folder layout?** Under the [Agent Skills open specification](https://agentskills.io), a skill's YAML `name` (`content-research-writer`) must match its immediate parent directory name (`content-research-writer/`). Keeping the skill inside `content-writer-skill/content-research-writer/` satisfies both the repository directory path and cross-agent skill discovery rules.
