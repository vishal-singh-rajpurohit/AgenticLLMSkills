# Cursor Adapter

Cursor natively supports the `agentskills.io` open standard (`SKILL.md`).

## Installation

### Project-scoped (`.cursor/skills/`)
```bash
./seo-strategist-growth-engine/adapters/install.sh --target cursor --scope project
```

### Global (`~/.cursor/skills/`)
```bash
./seo-strategist-growth-engine/adapters/install.sh --target cursor --scope global
```

On Windows PowerShell, use `./seo-strategist-growth-engine/adapters/install.ps1 -Target cursor -Scope project` (or `global`).
